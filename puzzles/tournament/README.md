# TAAI / TCGA / ICGA tournament sets

The puzzle sets of the TAAI, TCGA and ICGA computer nonogram tournaments,
2011–2023.  Each set has 1000 puzzles of 25x25.

The files are copied unchanged from `question/` in
[zxkyjimmy/NonogramRecord](https://github.com/zxkyjimmy/NonogramRecord),
which is licensed under the GNU General Public License v3.0 (see `LICENSE`).
